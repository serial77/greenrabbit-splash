# greenrabbit.es

One-page informational site for Green Rabbit Cannabis Social Club (Calp). Plain static
HTML/CSS with a little inline vanilla JS, generated by a zero-dependency Node script.

## Layout

| Path | What |
| --- | --- |
| `site.config.mjs` | **All club data** (legal name, CIF, address, hours, contact, min. age, TODO list) |
| `build.mjs` | Page templates, language registry (`LANGS`), JSON-LD, sitemap, robots, manifest → `dist/` |
| `src/i18n/*.mjs` | Copy per language: es, en, fr, de, it, nl, sv, ru, ar (Arabic is right-to-left, `ar-MA`) |
| `src/site.css`, `src/site.js` | Styles and script, inlined into every page at build time |
| `src/static/` | Copied verbatim: optimised images, fonts, favicons, OG image |
| `images/` | Original photos and logo (never modified, not deployed) |
| `scripts/compose.py`, `scripts/images.mjs` | Regenerate `src/static/` from `images/` |

## Commands

```sh
npm run build     # node build.mjs -> dist/
npm run preview   # build + serve dist/ on http://localhost:4173
npm install && npm run images   # only when photos/logo change (needs Python 3 + Pillow)
python3 scripts/fonts.py        # only after editing src/i18n/ar.mjs with new characters (needs fonttools + brotli)
```

## Languages

Spanish lives at `/`, every other language at `/<code>/`. To add or edit one, change its file in
`src/i18n/` (same keys as `en.mjs`) and its entry in `LANGS` in `build.mjs`. Legal pages stay in
Spanish, the governing language. Static asset URLs carry a content hash (`?v=…`), so regenerated
images and fonts reach visitors immediately despite long cache headers.

## Deploy (Vercel)

`vercel.json` sets build command `node build.mjs`, output `dist/`, no install step,
clean URLs with trailing slashes, cache and security headers. Pushing to `master`
deploys. The canonical domain is `https://www.greenrabbit.es` (`SITE_URL` in
`site.config.mjs`); the apex `greenrabbit.es` redirects to it via Vercel → Project →
Settings → Domains. Keep the two in sync if that ever changes.
