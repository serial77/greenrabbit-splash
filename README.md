# greenrabbit.es

One-page informational site for Green Rabbit Cannabis Social Club (Calp). Plain static
HTML/CSS with a little inline vanilla JS, generated by a zero-dependency Node script.

## Layout

| Path | What |
| --- | --- |
| `site.config.mjs` | **All club data** (legal name, CIF, address, hours, contact, min. age, TODO list) |
| `build.mjs` | Page templates + ES/EN copy, JSON-LD, sitemap, robots, manifest → `dist/` |
| `src/site.css`, `src/site.js` | Styles and script, inlined into every page at build time |
| `src/static/` | Copied verbatim: optimised images, fonts, favicons, OG image |
| `images/` | Original photos and logo (never modified, not deployed) |
| `scripts/compose.py`, `scripts/images.mjs` | Regenerate `src/static/` from `images/` |

## Commands

```sh
npm run build     # node build.mjs -> dist/
npm run preview   # build + serve dist/ on http://localhost:4173
npm install && npm run images   # only when photos/logo change (needs Python 3 + Pillow)
```

## Deploy (Vercel)

`vercel.json` sets build command `node build.mjs`, output `dist/`, no install step,
clean URLs with trailing slashes, cache and security headers. Pushing to `master`
deploys. Make `greenrabbit.es` the primary domain and redirect `www` to it in
Vercel → Project → Settings → Domains.
